# Install vpnctl

## Prerequisites

1. A Linux VPS (Ubuntu/Debian recommended).
2. OpenVPN installed with [angristan/openvpn-install](https://github.com/angristan/openvpn-install).
3. Python 3.10+.

Expected layout (current angristan defaults):

| Path | Purpose |
|------|---------|
| `/etc/openvpn/server/easy-rsa` | Easy-RSA |
| `/etc/openvpn/server/server.conf` | Server config |
| `/etc/openvpn/server/client-template.txt` | `.ovpn` template |
| `/var/log/openvpn/status.log` | Status log |
| `/var/run/openvpn-server/server.sock` | Management socket |

## Quick install

```bash
curl -fsSL https://raw.githubusercontent.com/amachulan/vpnctl/main/scripts/install.sh | sudo bash
```

Or manually:

```bash
git clone https://github.com/amachulan/vpnctl.git /opt/vpnctl
cd /opt/vpnctl
python3 -m venv .venv
source .venv/bin/activate
pip install .
sudo ln -sfn /opt/vpnctl/.venv/bin/vpnctl /usr/local/bin/vpnctl
sudo vpnctl install --systemd
sudo systemctl daemon-reload
sudo systemctl enable --now vpnctl
```

## Configure

- Config: `/etc/vpnctl/config.yaml`
- Token: `api.token` (generated by `vpnctl install`)
- UI: `http://127.0.0.1:8080/` (loopback by default)

Paste the token into the UI header once; it is stored in browser `localStorage`.

### Optional mail delivery

```yaml
mail:
  enabled: true
  smtp_host: smtp.example.com
  smtp_port: 587
  use_tls: true
  smtp_user: user
  smtp_password: secret
  from_addr: vpn@example.com
```

### Optional Telegram delivery

```yaml
telegram:
  enabled: true
  bot_token: "123:ABC"
  chat_id: "123456789"
```

## Reverse proxy (optional)

Keep vpnctl on `127.0.0.1:8080` and terminate TLS on nginx/caddy. Protect the UI with your own auth or keep it admin-only via VPN/SSH tunnel.

## Verify

```bash
vpnctl health
curl -s -H "Authorization: Bearer YOUR_TOKEN" http://127.0.0.1:8080/api/v1/clients
```

## Definition of done

1. angristan OpenVPN is up.
2. `vpnctl` systemd unit is active.
3. Issue a client in the UI, download `.ovpn`, connect.
4. Sessions shows the client; Disconnect works.
5. Revoke removes access (CRL + disconnect).
